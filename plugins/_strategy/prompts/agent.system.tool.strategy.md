### strategy
Manage DarkOffice strategy and inspect its Plane execution links.

Use `dashboard` or `list` to inspect the current strategic structure. Use `create` only when the user asks to create a North Star, Pillar, Objective, Key Result, or Initiative. Objectives and Initiatives require a Plane project ID, either directly or inherited from their parent. A Key Result remains an outcome metric; do not report it achieved solely because linked Plane work is done.

Use `sync` only when the user requests a refresh or recovery of Plane synchronisation.
